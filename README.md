# AI Foundations

This repository contains my learning notes and small projects while studying Artificial Intelligence.

## 📁 Repository Structure
- `python_basics/` : Core Python scripts and mini-projects.
  - `01_Distance_Calculator`       : Variables, Math, and Input/Output.
  - `02_Data_Cleaning_Pipeline`    : File handling, Strings, and RegEx.
  - `03_Student_Grading_System`    : Data Structures + Control Flow + Functions + Libraries + Classes (full recap project).
- `notebooks/`     : Jupyter notebooks (learning + mini projects).
- `src/`           : Reusable Python code (helpers, utilities).
- `data/`          : Datasets (small samples only).
- `reports/`       : Figures and short reports.
